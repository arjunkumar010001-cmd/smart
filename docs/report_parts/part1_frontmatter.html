ABSTRACT

The traditional recruitment process is plagued by inefficiencies including manual resume screening, subjective evaluations, unconscious bias, and a lack of standardized assessment mechanisms. These challenges lead to prolonged hiring cycles, poor candidate experiences, and discriminatory outcomes. This project presents Smart Hiring, an end-to-end AI-powered recruitment platform that automates and optimizes the entire hiring pipeline across six integrated phases.

The system implements: (1) Intelligent Job Posting with AI-optimized descriptions using Large Language Models (Groq LLaMA-3.3-70B); (2) Resume Refinery powered by Sentence-BERT (all-MiniLM-L6-v2) semantic embeddings and TF-IDF vectorization for multi-dimensional candidate-job matching; (3) Smart Assessment Engine with AI-generated adaptive questions, real-time code execution via Piston/Judge0 sandboxes, Monaco Editor integration, face-detection-based proctoring using TinyFaceDetector, and a nine-mechanism anti-cheating module; (4) AI-Powered Interviews featuring an interactive AI avatar with Text-to-Speech/Speech-to-Text capabilities and automated response evaluation; (5) Fairness Audit Engine implementing five mathematical fairness metrics (Demographic Parity, Disparate Impact with the 80% Rule, Equal Opportunity, Equalized Odds, and Predictive Parity) alongside automated bias correction; and (6) Digital Onboarding with offer letter generation, digital signature acceptance (SHA-256), document verification, NDA e-signing, and IT provisioning workflows.

The platform is built on a Flask-MongoDB-REST architecture with JWT-based Role-Based Access Control (RBAC), exposing 172+ API endpoints. The system incorporates a four-provider AI waterfall (Groq → Claude → OpenAI → Static Fallback) ensuring zero-downtime question generation, and employs WebSocket-based real-time communication via Flask-SocketIO for the interview module. Experimental evaluation demonstrates semantic matching accuracy improvements of up to 40% over keyword-based approaches, assessment integrity enforcement through automated session termination, and fairness metric compliance across all five audit dimensions.

Keywords: Artificial Intelligence, Natural Language Processing, Sentence-BERT, Resume Matching, Fairness Auditing, Proctoring, Anti-Cheating, Recruitment Automation, Flask, MongoDB, Large Language Models.
