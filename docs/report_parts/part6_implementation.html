5.3 Frontend Implementation

The frontend is built with vanilla HTML5, CSS3, and JavaScript (ES6+) — intentionally avoiding framework dependencies (React, Vue, Angular) to minimize bundle size and maximize deployment flexibility.

Key Frontend Technologies:

  • Monaco Editor (v0.44.0): VS Code's editor component for coding questions with IntelliSense, syntax highlighting, and error indicators.
  • face-api.js (v1.7.12): TensorFlow.js-based face detection running entirely in the browser. Models loaded locally from frontend/models/ (TinyFaceDetector, ~190KB).
  • Web Speech API: Native browser APIs for Text-to-Speech (SpeechSynthesis) and Speech-to-Text (SpeechRecognition).
  • MediaRecorder API: Records webcam video+audio as video/webm;codecs=vp9,opus for evidence preservation.
  • CSS Custom Properties: Design tokens for theming (--sa-primary, --sa-accent, etc.) enabling dark/light mode support.

5.5 Sample Code and Explanations

5.5.1 SBERT Semantic Matching (ml_matching_service.py):

class MLMatchingService:
    """Production-ready semantic matching using
    Sentence-BERT embeddings"""

    def __init__(self):
        self.sbert_model = None
        self.tfidf_vectorizer = TfidfVectorizer(
            max_features=5000,
            stop_words='english',
            ngram_range=(1, 2)
        )
        self._load_model()

    def _load_model(self):
        """Load SBERT model (all-MiniLM-L6-v2)"""
        if SBERT_AVAILABLE:
            self.sbert_model = SentenceTransformer(
                'all-MiniLM-L6-v2')
            logger.info("SBERT model loaded: "
                       "all-MiniLM-L6-v2 (384-dim)")

    def compute_semantic_similarity(
        self, text1: str, text2: str
    ) -> float:
        """Compute cosine similarity between two texts
        using SBERT embeddings"""
        if self.sbert_model:
            embeddings = self.sbert_model.encode(
                [text1, text2],
                convert_to_numpy=True
            )
            # Cosine similarity
            similarity = np.dot(
                embeddings[0], embeddings[1]
            ) / (
                np.linalg.norm(embeddings[0]) *
                np.linalg.norm(embeddings[1])
            )
            return float(similarity)
        else:
            # TF-IDF fallback
            return self._tfidf_similarity(
                text1, text2)

5.5.2 Fairness Metrics Computation (fairness_engine.py):

class FairnessMetrics:
    """5-metric fairness calculator using numpy/pandas"""

    def __init__(self, predictions, labels,
                 sensitive_features, favorable_label=1):
        self.predictions = np.array(predictions)
        self.labels = np.array(labels)
        self.sensitive_features = np.array(
            sensitive_features)
        self.favorable_label = favorable_label
        self._compute_group_statistics()

    def demographic_parity(self) -> dict:
        """P(Ŷ=1|A=0) should equal P(Ŷ=1|A=1)"""
        selection_rates = {}
        for group in self.groups:
            stats = self.group_stats[group]
            selection_rates[str(group)] = \
                stats['selection_rate']

        rates = list(selection_rates.values())
        max_diff = max(rates) - min(rates)
        is_fair = max_diff <= 0.1  # 10% threshold

        return {
            'metric': 'demographic_parity',
            'selection_rates': selection_rates,
            'max_difference': round(max_diff, 4),
            'is_fair': is_fair,
            'threshold': 0.1
        }

    def disparate_impact(self) -> dict:
        """80% Rule: min(SR) / max(SR) >= 0.8"""
        rates = [self.group_stats[g]['selection_rate']
                 for g in self.groups]
        ratio = min(rates) / max(rates) \
            if max(rates) > 0 else 0
        return {
            'metric': 'disparate_impact',
            'ratio': round(ratio, 4),
            'is_fair': ratio >= 0.8,
            'threshold': 0.8
        }

5.5.3 Anti-Cheating Module (smart-assessment.html):

// ANTI-CHEAT ENGINE — BRUTAL MODE
function initAntiCheat() {
    // 1. Tab switch detection
    document.addEventListener('visibilitychange',
        () => {
        if (document.hidden) {
            addStrike('Tab switch detected');
        }
    });

    // 2. Window blur detection
    window.addEventListener('blur', () => {
        addStrike('Window lost focus');
    });

    // 3. Copy/Paste blocking
    ['copy','paste','cut'].forEach(evt =>
        document.addEventListener(evt, e => {
            e.preventDefault();
            logViolation(evt, 'Clipboard blocked');
        })
    );

    // 4. Right-click disabled
    document.addEventListener('contextmenu',
        e => e.preventDefault());

    // 5. DevTools detection
    setInterval(() => {
        if (window.outerWidth - window.innerWidth
            > 160) {
            addStrike('DevTools detected');
        }
    }, 2000);

    // 6. Keyboard shortcut blocking
    document.addEventListener('keydown', e => {
        if (e.key === 'F12' ||
            (e.ctrlKey && e.shiftKey &&
             ['I','J','C'].includes(e.key))) {
            e.preventDefault();
            logViolation('keyboard',
                'Blocked: ' + e.key);
        }
    });
}

function addStrike(reason) {
    strikes++;
    logViolation('strike', reason);
    if (strikes >= 3) {
        terminateSession(
            'Auto-terminated: 3 strikes');
    }
}
